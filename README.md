# SI 26 — Sistem Informasi 26

Website informasi kelas **Sistem Informasi 26** yang dirancang untuk memudahkan mahasiswa mengakses informasi kelas dalam satu tempat.

## ✨ Fitur

- 🏠 **Beranda** — Halaman utama website.
- 🕒 **Jam Digital** — Menampilkan waktu secara langsung.
- 📅 **Jadwal Kelas** — Informasi jadwal perkuliahan.
- 👥 **Anggota Kelas** — Informasi anggota kelas.
- 🖼️ **Galeri** — Dokumentasi dan foto kegiatan kelas.
- 💬 **Pesan Anonim** — Fitur untuk mengirim pesan secara anonim.
- 🔐 **Panel Admin** — Pengelolaan informasi tertentu oleh administrator.
- ☁️ **Firebase** — Integrasi layanan backend untuk fitur yang didukung.

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- Firebase
- Git dan GitHub (opsional)
- Vercel untuk deployment (opsional)

## 🚀 Cara Menjalankan

1. Clone atau download repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan file `index.html` berada di folder utama.
4. Jalankan menggunakan ekstensi **Live Server** atau buka `index.html` melalui browser.
5. Jika menggunakan Firebase, pastikan konfigurasi Firebase sudah diisi dengan benar.

## ⚙️ Konfigurasi Firebase

Jika project menggunakan Firebase:

1. Buat project melalui [Firebase Console](https://console.firebase.google.com/).
2. Aktifkan layanan yang diperlukan oleh website.
3. Sesuaikan konfigurasi Firebase di dalam kode.
4. Atur Firebase Security Rules sesuai kebutuhan dan hak akses pengguna.

**Catatan keamanan:** Jangan menyimpan password, private key, atau kredensial rahasia di dalam kode frontend. Batasi akses database menggunakan Security Rules yang sesuai.
